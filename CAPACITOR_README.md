# PAY8 — Build & Ship to Google Play Store

This document explains how to package the PAY8 web app as a real Android
APK / AAB ready for Google Play Store. The web app itself is a
production-grade PWA (manifest + icons + service worker ready) so it
installs natively on Android home screens. To distribute via Play Store,
wrap the PWA with one of the two paths below.

## Why this works as a "real" app

- The app is mobile-first, full-screen, no browser chrome
- `manifest.json` declares `display: "standalone"`, navy `theme_color`,
  and proper icons (192, 512, maskable, 180 for iOS)
- `viewportFit: cover` + `env(safe-area-inset-*)` so it respects notches
- Pin pad, sheet modals, bottom-nav FAB — all native-app interaction
  patterns

## Option A — Trusted Web Activity (TWA, recommended, lightest APK)

Best for Play Store if your app is primarily a PWA. TWA wraps the PWA
in a thin native shell with no browser UI, supports Play Sign-In and
Push Notifications via Digital Asset Links.

```bash
# 1. Install Bubblewrap CLI (Node)
npm install -g @bubblewrap/cli

# 2. Initialize the Android project (from this repo root)
bubblewrap init --manifest=https://your-pay8-domain.com/manifest.json

# 3. Build the signed AAB (Android App Bundle for Play Store)
bubblewrap build

# 4. Upload the .aab to Play Console
#    - Package ID: com.pay8.wallet (or your chosen ID)
#    - Sign with the keystore Bubblewrap generated for you
```

You will also need to host a `/.well-known/assetlinks.json` on your
domain to verify ownership. Bubblewrap generates a template.

## Option B — Capacitor (richer, native plugins)

Use if you need camera, biometrics, NFC for transit-card emulation,
background tasks, etc.

```bash
# 1. Install Capacitor
npm install @capacitor/core @capacitor/cli @capacitor/android
npm install @capacitor/camera @capacitor/biometric-auth @capacitor/preferences

# 2. Init
npx cap init PAY8 com.pay8.wallet --web-dir=out

# 3. Build the web app, then sync to native
bun run build
npx cap add android
npx cap sync

# 4. Open in Android Studio, then Build > Generate Signed Bundle
npx cap open android
```

Capacitor plugins you'll likely want:

- `@capacitor/camera` — replace the file-input fallback on Scan screen
  with the real device camera
- `@capacitor-community/biometric-auth` — fingerprint / Face Unlock
  login instead of (or in addition to) the 6-digit PIN
- `@capacitor/preferences` — already covered by localStorage on web;
  this gives native-equivalent storage
- `@capacitor-community/barcode-scanner` — replace `simulateScan`
  with real QR detection (ML Kit under the hood)
- `@capacitor/haptics` — soft tap feedback on PIN entry / pay confirm

## Option C — Tauri Mobile (smallest binary, single-binary native)

```bash
cargo install tauri-cli
cargo tauri android init
cargo tauri android build
```

## Tablet support

The app already centers a phone-width layout on tablets (max-w-md).
To use the wider tablet canvas with split-view (master/detail), expand
the `AppShell` container with a `md:max-w-2xl lg:max-w-4xl` breakpoint
and render the side panel for Inbox → detail or Transactions → detail.

## Pre-launch checklist (Play Store)

- [ ] Host the production build at your domain (e.g. pay8.app)
- [ ] HTTPS enabled (required for PWA install + camera + service worker)
- [ ] `manifest.json` `start_url` matches production domain
- [ ] Generate a 512×512 maskable icon (already in `/public/icons/`)
- [ ] Generate Play Store feature graphic (1024×500)
- [ ] Add screenshot generator output (phone + 7" tablet + 10" tablet)
- [ ] Submit Privacy Policy URL (required for financial apps)
- [ ] Submit DPA / Data Processing notice (BSP requirement for e-money)
- [ ] Declare relevant permissions in Play Store listing:
      - Camera (for QR scan + selfie KYC)
      - Storage (for ID uploads)
      - Biometric (fingerprint login)
- [ ] Target audience: 18+ (financial app)
- [ ] Content rating: IARC questionnaire → Everyone / Teen typically

## Regenerate icons

The icons in `/public/icons/` are generated by
`scripts/gen-icons.ts`. Re-run with:

```bash
bun scripts/gen-icons.ts
```

## Local dev

```bash
bun run dev     # http://localhost:3000
bun run lint    # ESLint check
```
